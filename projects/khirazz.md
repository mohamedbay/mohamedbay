## The product

The web interface and Electron desktop edition share the application experience. Each device keeps local records; optional synchronization brings connected devices together.

## My work

Application development and technical implementation across the shared interface, local persistence, synchronization workflows and Windows delivery. This overview groups the product and its release tooling as one project.

## Workflows

- Operate the shared point-of-sale interface in the browser or Windows desktop edition.
- Save locally before attempting synchronization.
- See synchronization progress and pending records.
- Build and distribute Windows application updates.

## Technology

JavaScript · Electron · IndexedDB · web application interfaces
